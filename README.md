WellSmartBook – AI-Powered Health and Fitness Management System



Project Overview

WellSmartBook is a web-based health and fitness management system developed as a Final Year Project (FYP). The system aims to help users maintain a healthier lifestyle by integrating health monitoring, artificial intelligence, fitness guidance, and online booking features into a single platform.



Main Features

User Management – User registration, login, and profile management.



Health Dashboard – BMI calculation, calorie tracking



AI Meal Scanner – Recognizes food images and provides estimated calories and nutritional information.



AI Ingredient Scanner – Identifies raw ingredients from uploaded images.



Recipe Recommendation – Recommends recipes based on recognized ingredients.



Interactive Gym Map – Helps users search for and locate nearby gyms.



Fitness Coach Booking – Allows users to view coaches, select available sessions, and make bookings.



Online Payment – Integrates Stripe for secure payment processing.



Interactive Body Map – Provides muscle-specific workout information and exercise videos.



Admin Management – Supports administrative management of system users and content.

This project was developed for academic purposes as part of a Final Year Project. It demonstrates the integration of web technologies, artificial intelligence, database management, and external APIs into a health and fitness management platform.
